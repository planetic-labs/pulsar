# Служебные скрипты Pulsar

В этой папке собраны инструменты для обслуживания базы данных, управления импортом и проведения массовых операций.

## Основные операции
- **`ingest_drive_file.py`**: Ядро системы импорта. Выполняет полный цикл обработки одного файла: скачивание -> извлечение аудио -> транскрибация -> нарезка на чанки -> индексация.
- **`interactive_ingest.py`**: Интерактивная консольная утилита для выбора и импорта файлов из Google Drive вручную.
- **`process_drive_folder.py`**: Массовый импорт всех видео из указанной папки Google Drive.

## Обслуживание и исправление данных
- **`verify_integrity.py`**: Старый ремонтный инструмент, который изменяет SQLite, Manticore и файлы. Запускается только с явным `--apply`; для диагностики используйте read-only вариант ниже.
- **`verify_integrity_readonly.py`**: Безопасный аудит тех же хранилищ без исправлений, удаления файлов, записи в SQLite/Manticore и постановки задач. Подробности ограничиваются через `--max-details`; значение `0` выводит все найденные несоответствия.
  Запуск в dev: `docker compose exec -T pulsar python scripts/verify_integrity_readonly.py --max-details 20`.
- **`patch_raw_text.py`**: Применяет новые правила автозамены (из `app/transcription/postprocessing.py`) ко всем уже скачанным сырым (raw) файлам транскрибаций.
- **`rebuild_db_from_raw.py`**: Полная пересборка базы SQLite и нормализованных файлов на основе сырых JSON-данных. Полезно при изменении логики нарезки чанков или после массового патча текста.
- **`sync_titles.py`**: Синхронизирует названия видео и структуру папок из Google Drive в локальную базу данных.
- **`register_transcript.py`**: Позволяет вручную зарегистрировать в системе существующий файл транскрибации.

## Индексация и поиск
- **`reindex_search.py`**: С `--full` строит отдельную staging-таблицу, проверяет число документов и только затем переключает её в active; прежняя таблица сохраняется для отката.
- **`queue_all_for_indexing.py`**: Идемпотентно ставит все видео в очередь Stage 3, не очищая рабочую таблицу Manticore.
- **`search_cli.py`**: Простая консольная утилита для тестирования гибридного поиска по базе.

## Аудио и голос
- **`extract_audio.py`**: Утилита для извлечения WAV-дорожки из видеофайла с помощью FFmpeg.

## Системные инструменты
- **`drive_cli.py`**: Помощник для работы с Google Drive (инициализация токена, листинг файлов).
- **`cleanup_gallery_duplicates.py`**: Удаляет временные файлы и дубликаты, помеченные маркерами "gallery".
