# VideoDB AI

MVP-сервис для глубокого поиска по архиву видео с использованием AI-транскрибации и семантического поиска.

## Основные возможности

- **Умный поиск**: Гибридный поиск (RRF), сочетающий полнотекстовый поиск (Keyword) и семантический поиск по смыслу (Gemini Embeddings).
- **Адаптивный интерфейс**: Полностью отзывчивый дизайн (Mobile First), оптимизированный для работы на смартфонах, планшетах и десктопах.
- **Студия редактирования**: Встроенный редактор для правки транскрибаций с автоматическим сохранением и мгновенным пересчетом векторных эмбеддингов для поиска.
- **Мульти-движковая транскрибация**: Поддержка и сравнение результатов различных движков (Deepgram, Whisper и др.).
- **Интеграция с Google Drive**: Автоматический импорт, стриминг видео напрямую из облака и экспорт готовых текстов.
- **Мониторинг**: Панель состояния индекса и процесса обработки видео.

## Технологический стек

- **Backend**: FastAPI (Python 3.12+)
- **Database**: PostgreSQL с расширением `pgvector` для хранения эмбеддингов.
- **Frontend**: Tailwind CSS, Vanilla JS, Lucide-icons (иконки в стиле Plus Jakarta Sans).
- **AI**: Google Gemini API (Embeddings), Deepgram API (Transcription).
- **Инструменты**: `uv` (пакетный менеджер), Docker & Docker Compose.

## Быстрый старт

### 1. Подготовка окружения
Убедитесь, что у вас установлен `uv`.

```bash
uv sync
```

### 2. Настройка конфигурации
Создайте файл `.env` на основе `.env.example`:
- `APP_ACCESS_TOKEN`: Ключ для входа в систему.
- `GOOGLE_AI_API_KEY`: Ключ для работы с Gemini (векторы).
- `DEEPGRAM_API_KEY`: Ключ для транскрибации.
- `POSTGRES_URL`: URL вашей базы данных PostgreSQL.

### 3. Запуск сервера

```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Или через Docker:
```bash
docker compose up -d --build
```

## Управление данными (CLI)

Проект содержит набор скриптов в папке `scripts/` для управления архивом:

- **Авторизация в Drive**: `python scripts/drive_cli.py auth-init`
- **Импорт видео**: `python scripts/ingest_drive_file.py <FILE_ID>`
- **Переиндексация**: `python scripts/reindex_search.py`
- **Очистка дублей**: `python scripts/cleanup_gallery_duplicates.py`

## Структура проекта

- `app/` — Основной код приложения (FastAPI, логика поиска, БД).
- `templates/` — HTML-шаблоны с адаптивной версткой.
- `scripts/` — Утилиты для обслуживания и импорта данных.
- `storage/` — Локальное хранилище для кэша транскрибаций.

## Безопасность

Доступ к API и UI защищен токеном авторизации. Система поддерживает сессионную аутентификацию и передачу токена через URL параметры для быстрой интеграции.
